# G1 Workshop implementation plan

Owner authorized planning and implementation together. Extend the existing local Workshop branch; preserve its uncommitted work.

1. Pin Unitree's official BSD-3-Clause G1 23-DoF URDF and only its referenced meshes. Retain license, source commit and file hashes. No RoboLabs assets.
2. Add a G1 learning-model starter inside Workshop. Persist it as a planned reference, not owned hardware. Use manufacturer model data; do not invent dimensions, component ratings or verified assembly instructions.
3. Add a dedicated URDF viewer to Build and Overview with local-only asset loading, selectable links, hide/show, exploded inspection, reset and limit-clamped joint sliders. Reuse the workshop scenery. Preserve a textual link/joint interface when WebGL is unavailable.
4. Add guided link exploration and Wrench commands for explain/select, explode, reset, next and joint posing through the viewer's actual controller. Report unsupported actions accurately. Link assembly order is educational, not verified fastening order. Walking/jumping and hardware control are out of scope for this integration.
5. Verify asset references/hashes, joint bounds and command parsing; run TypeScript, production export and focused regression tests. Inspect in the local browser. No deployment or shared-branch push.
