# Wrench-first Workshop

Goal: one conversational input surface for real builds and fictional concepts, with optional scan capture guidance.

- Explain photo-first intake and optional Scaniverse/Intel RealSense scans in a compact Workshop card. All calls to action focus Wrench or its paperclip.
- Extend the shared file classifier to GLB/OBJ/PLY. Store meshes locally on the selected robot (or create a clearly unmeasured scan record), without guessing scale or physical properties.
- Route Workshop photo/scan controls and spec changes into Wrench; retain read-only inspection and optional simulation/view controls.
- Add text-driven local concept generation/regeneration and the existing supported modification grammar to the main composer. Preserve history, label planned output, and refuse unsupported changes.
- Keep selected robot identity explicit in Workshop context so attachments never silently target an arbitrary robot.
- Verify classifier and command behavior, selected-robot media persistence, browser flows, regression tests and production build.
