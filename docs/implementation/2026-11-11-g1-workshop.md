# Unitree G1 Workshop integration

Plan: `docs/superpowers/plans/2026-11-11-g1-workshop.md`.

Implemented the official G1 23-DoF educational reference inside Workshop. Add it via **Add a robot → Explore Unitree G1 humanoid**, then use Build or Overview. The reference is saved as planned and never implies hardware ownership.

Assets are pinned to Unitree commit `725b59b6de39a26c425632120c89f23c49a36f1e`. The local asset bundle contains the unmodified URDF, its 29 referenced STL meshes, upstream README, BSD-3-Clause license and SHA-256 provenance manifest (approximately 20 MB; fetched only when the model view opens). No RoboLabs code or models were copied.

The viewer provides link picking/list selection, per-link visual hiding, exploded inspection, reset, joint-limit-clamped sliders and lightweight records. Wrench supports `explode humanoid`, `reset humanoid`, `next humanoid part`, `explain humanoid part`, `select humanoid pelvis`, and `pose left_knee_joint to 30 degrees`. Existing guided-build requests are bridged to link exploration. Link order is explicitly educational, not a verified fastening sequence.

No gait controller, balance/collision validation, dynamic humanoid simulation, hardware connection or deployment is included. No real model API calls were needed for the browser command checks.
