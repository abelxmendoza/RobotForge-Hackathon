Andino

Differential-drive ground robot

An open-source ROS 2 robot from Ekumen, built to teach real robotics on a budget: two driven wheels and a caster, a spinning lidar on top, a Raspberry Pi for a brain. It is the first robot in the Robodex that RobotForge did not design — its spec here was read out of the official project's own files.

battery3x 18650 Li-ion cells, ~11.1 V nominal (official BOM holder); capacity varies by cell — the spec uses 2600 mAh as a labelled estimate
chassis0.25 m long x 0.10 m wide base deck (official URDF base.yaml); overall width 0.153 m across the wheels, wheel track 0.128 m
computerRaspberry Pi 4 + Arduino Nano (official BOM)
drivetraindifferential — 2 driven wheels + ball caster
ground_clearance~0.03 m — estimate; the URDF base plane rides at wheel radius (0.0331 m)
height~0.18 m — estimate derived from the URDF deck stack
mass3.364 kg — the sum of the official URDF link masses (several are round values upstream)
motors2x DG01D-E gearmotors with encoders, 48:1 gearbox, rated 3-9 V (SparkFun listing linked from the official BOM), driven via an L298N
sensorsRPLIDAR A1M8 2D lidar (top), Raspberry Pi Camera V2 (front), BNO055 IMU, wheel encoders
wheels66.2 mm diameter x 25 mm — official wheel.yaml radius 0.0331 m

Provenance: Ekumen-OS/andino (official project repository) · license: BSD-3-Clause · source
License is per-package LICENSE files in the repo (each reads BSD 3-Clause, (c) 2023 Ekumen Inc.); the repo root carries no single LICENSE file. Spec values were read from andino_description/config/andino/*.yaml and the andino_hardware BOM.

Recorded runs:
  • drive error 1.497% · turn error 3.425 deg · odometry distance error 0.003% · odometry heading error 8.285 deg · transport: gz-transport bindings source: Gate run 1 on scythe, 2026-10-26, build/gate-andino-1/gate-report.json — run verdict MARGINAL (motion vs ground truth PASS; odometry heading MARGINAL)
  • drive error 0.347% · turn error 9.104 deg · odometry distance error 0.003% · odometry heading error 11.624 deg · transport: gz-transport bindings source: Gate run 2 on scythe, 2026-10-26, build/gate-andino-2/gate-report.json — run verdict FAIL (turn vs ground truth MARGINAL at 9.104 deg; odometry heading FAIL at 11.624 deg)

Two recorded runs on scythe (2026-10-26), no PASS — recorded as measured; the locked thresholds were not touched. The drive is excellent in both runs (1.497% / 0.347% against ground truth, odometry distance error 0.003%), but the pivot turn is the failure mode: the robot is heavy (3.364 kg — the sum of the official URDF link masses) on two passive caster balls, so in a turn it physically under-rotates while its wheel odometry (perfect joint integration) over-reads heading by 8.285-11.624 degrees. The gate's own suspect line names wheel_separation / caster scrub. Diagnosis recorded; the verdict was not massaged.
